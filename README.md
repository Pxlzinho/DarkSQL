# DarkSQL
DarkSQL v2.0 - Ferramenta avançada de automação SQL Injection. Detecta automaticamente vulnerabilidades, enumera bancos de dados, tabelas e extrai dados massivamente. Desenvolvida para testes de segurança autorizados, gera relatórios HTML profissionais.  Aviso: Use apenas com autorização. Desenvolvedor não se responsabiliza pelo uso indevido.
